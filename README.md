# SQL-тренажер на основі Gemini API

PoC-проєкт до курсу «Хмарні обчислення» (Завдання 2). Вебзастосунок, у якому **Gemini** генерує
завдання з SQL, перевіряє розв'язки студента, дає підказки й пояснює помилки.

## Можливості
- генерація нових завдань трьох рівнів (легкий / середній / складний) на вибрану тему;
- виконання запитів на навчальній БД інтернет-магазину (SQLite, режим лише для читання);
- автоматична перевірка: результат студента порівнюється з еталонним розв'язком моделі;
- відгук від Gemini: що не так і навідна підказка (без готової відповіді);
- поступові підказки (1 → 3, від ідеї до каркаса запиту) та пояснення розв'язку крок за кроком;
- офлайн-режим без ключа (вбудовані завдання) — для демонстрації без інтернету.

## Запуск (Windows)
1. Встановити Python 3.10+ (https://python.org, галочка *Add to PATH*).
2. Отримати безкоштовний ключ: https://aistudio.google.com → **Get API key** → **Create API key**.
3. У папці проєкту:
   ```bat
   pip install -r requirements.txt
   set GEMINI_API_KEY=ваш_ключ
   python app.py
   ```
   (PowerShell: `$env:GEMINI_API_KEY="ваш_ключ"`)
4. Відкрити http://127.0.0.1:5000

Модель можна змінити змінною `GEMINI_MODEL` (за замовчуванням `gemini-flash-latest`;
якщо вона недоступна, застосунок сам вибере доступну flash-модель через `models.list`).

## Архітектура
```
Браузер (templates/index.html)
   │  fetch /api/*
Flask (app.py) ──── db.py ──── SQLite shop.db (read-only, authorizer, таймаут 3 с)
   │
gemini.py ── HTTPS ──► Gemini API  POST /v1beta/models/{model}:generateContent
```
| Ендпоінт | Що робить | Використання Gemini |
|---|---|---|
| `POST /api/task` | нове завдання | генерація JSON (`responseMimeType: application/json`), еталон перевіряється на БД |
| `POST /api/run` | виконати запит | — |
| `POST /api/check` | перевірити розв'язок | аналіз помилки й відгук |
| `POST /api/hint` | підказка 1–3 | поступові підказки |
| `POST /api/solution` | показати розв'язок | пояснення крок за кроком |

Еталонні розв'язки зберігаються лише на сервері, тому їх не видно в браузері.

## Безпека
- БД відкривається в режимі `mode=ro`, а `sqlite3.set_authorizer` дозволяє лише читання;
- один запит за раз, обмеження 200 рядків і 3 секунди на виконання;
- API-ключ береться зі змінної середовища і **не зберігається в репозиторії**.

## Структура
```
app.py              Flask-сервер і REST API
gemini.py           клієнт Gemini API (REST, urllib) + промпти + офлайн-завдання
db.py               створення навчальної БД, безпечне виконання та порівняння результатів
templates/index.html  інтерфейс
```
